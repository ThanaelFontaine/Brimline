# Brimline 0.2.1

Brimline 0.2.1 is the version you can install without building it. The app itself is the same as 0.2.0. It is still private: the repository and the site are not public yet, so the links below work once they are.

## What is new

- **A disk image with every release**: `Brimline.dmg`, with its SHA-256 next to it. Open it and drag Brimline onto Applications.
- **Install in one line**: `curl -fsSL https://brimline.thanaelfontaine.eu/install.sh | sh` downloads that image, checks its SHA-256, installs Brimline in `/Applications`, links the `brimline` command and opens the app. Run it again to update.
- **One app for Apple silicon and Intel** (Intel not tried on a real Mac yet).
- **A clearer README**: the install line first, a short "How it works", and it says plainly that Brimline is a Mac app only, with no Windows or Linux version.

## Good to know

- Brimline is not notarized by Apple (that needs a paid Apple Developer account). A disk image downloaded in a browser needs **Open Anyway** once, in System Settings, Privacy & Security ([Apple's page](https://support.apple.com/en-us/102445)). The one-line installer downloads with `curl`, and in our tests on macOS 27 the app it installs is not quarantined.
- What 0.2.0 said was not tried is still not tried: no paid plan of ChatGPT, Grok or Cursor, no MacBook with a notch, no Sonoma Mac.
