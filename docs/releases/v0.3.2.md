# Brimline 0.3.2

Brimline 0.3.2 changes nothing in what the app does. It changes what happens when a release is published: the release workflow now announces it in a Discord channel.

## What is new

- **Each release is announced on Discord.** After the release workflow publishes a release, it posts the version, the commits since the previous release (the version commit itself left out) and the links of the release and of its disk image, in the maintainer's Discord channel (`scripts/announce_release.py`, secret `DISCORD_RELEASES_WEBHOOK_URL`). Without the secret the step is skipped with a warning, and a failed announcement never fails the release: the release does not depend on it.

## Good to know

- Nothing changes for the person who installs or runs Brimline: the app, its settings and its signing are those of 0.3.1, so an update from 0.3.1 keeps the Accessibility permission.
- The announcement reads only the public release and its commits, and posts through a webhook whose address is a secret of the repository, never printed.

## Install

See [docs/install.md](../install.md). The one-line installer, run again, updates Brimline.
