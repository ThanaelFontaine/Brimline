# Sightglass 0.1.0

First version of Sightglass, a macOS menu bar app that shows how much of your Claude limits each of your accounts has used. It is private: the repository and the site are not public yet, nothing is announced.

## What works

- **Several Claude accounts at once** (used daily with four), each named by its email address: the five hour session, the week across all models and the week per model, with percentages in text and reset times.
- **Menu bar level glyph** that follows the account closest to a limit.
- **`sightglass` command** with `status --json`, `accounts --json` and `mcp`: the JSON states the age of every number and writes every key.
- **Local MCP server** (`sightglass mcp`): `list_accounts`, `get_usage` and `best_account`, so an agent can pick the account with the most room left.
- **Cache without secret**: the cache type has no field for a token, it is written readable by your user only, and a test checks the written file. Sign-ins are read from the Keychain, by exact service name, never written.
- **Design**: colors, glyph and app icon, light and dark mode, never color alone. English and French.
- **Hardening**: redirects refused, usage answer limited to 256 KiB, MCP messages to 1 MiB.

## What does not work yet

- **ChatGPT, Gemini and Grok** are not supported: only Claude accounts are read.
- **MacBook Pro and macOS 14 (Sonoma)**: not tried yet, only the Mac mini has been used.
- **The usage endpoint is not documented by Anthropic**: it may change or stop answering without notice, and Sightglass says so in words when it does. See [Is this allowed by Anthropic?](../faq.md#is-this-allowed-by-anthropic) in the FAQ.
